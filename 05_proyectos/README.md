## 🧠 La mentalidad de proyectos

Antes de escribir código, las personas programadoras profesionales hacen 3 preguntas:

1. **¿Qué debe hacer el programa?** *(requisitos)*
2. **¿Qué datos necesita?** *(entrada)*
3. **¿Qué debe mostrar al final?** *(salida)*

Para cada proyecto de este módulo encontrarás:

- ✅ **Los requisitos** en su README.
- ✅ **El código completo y comentado** para leer y ejecutar.
- 🚀 **Ideas de mejora** al final de cada README — el verdadero aprendizaje empieza cuando modificas un proyecto que funciona.

## 💡 Cómo trabajar cada proyecto

1. **Ejecútalo primero**: `python3 05_proyectos/01_adivina_el_numero/juego.py`
2. **Léelo línea por línea**: cada bloque importante tiene un comentario del porqué.
3. **Cámbiale algo pequeño**: cambia el rango de números, agrega un mensaje, modifica una regla.
4. **Implementa una mejora sugerida** en el README.
5. Cuando el programa deje de funcionar por tu cambio: **¡bienvenida a la programación real!** Depura, lee el error, corrige. Ese proceso es el aprendizaje.

## 🕳️ Errores que verás (¡y cómo sobrevivirlos!)

| Error | Qué significa | Qué hacer |
|-------|---------------|-----------|
| `ValueError: invalid literal for int()` | El usuario escribió texto donde esperabas número | Valida la entrada antes de convertirla (lo verás en proyecto 01) |
| `IndentationError` | La indentación está mal | Revisa que todos los bloques tengan 4 espacios consistentes |
| `NameError: name 'x' is not defined` | Usas una variable que no existe | Revisa que la hayas definido antes |
